# Nanozyme Image Analysis

用于纳米酶活性检测的数据处理与图像分析。

## Material

CuMnZnS nanozyme

## Functions

- Image color analysis
- RGB extraction
- Abs652 calculation
- Activity curve plotting
- Linear fitting
- R² calculation
- Error bar analysis

## Output

- Activity curve
- Fitting equation
- Slope
- R² value
- Activity comparison table
